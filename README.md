📄 Documentação do Projeto: GESTÃO-FESTA
📋 Visão Geral
GESTÃO-FESTA é um sistema de gestão para eventos e festas desenvolvido para organização e controle de atividades festivas.

🛠️ Tecnologias Utilizadas
☕ Linguagens: Java

🏗️ Framework: Spring Boot

📊 Banco de Dados: SQLite (etcctrace.db)

📦 Gerenciador de Dependências: Maven

🔀 Controle de Versão: Git

🔧 Configuração do Ambiente
📋 Pré-requisitos
☕ Java JDK 11 ou superior

🏗️ Maven 3.6+

💻 IDE (Eclipse, IntelliJ IDEA ou VS Code)

📊 SQLite (opcional para visualização do banco)

🏗️ Build e Execução
📥 Clone o repositório

🎯 Importe o projeto como projeto Maven na sua IDE

🔄 Execute o comando para baixar as dependências:

bash
mvn clean install
⚡ Execute a aplicação:

bash
mvn spring-boot:run
🌐 Acesse a aplicação no navegador
